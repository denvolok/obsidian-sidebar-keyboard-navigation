# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] 2026-07-25

### Added

- **File explorer** new action: open search in the focused folder using the slash (`/`) key.
- Support new tool window – **Search**
	- The actions and bindings are similar to the ones in the File Explorer. Press `?` to observe all available actions.
	- Some tips related to the Search functionality can be found in [README](README.md#search-toolbar)

### Fixed

- Correctly resolve copied folder paths, containing a dot (`.`) in the folder name.

## [1.0.2] 2026-03-25

### Fixed

- Allow to navigate nested entries in context menu
